# Glossary

**Body** — NixOS, Plasma, hardware, processes, and system state.

**Mind** — the cognitive substrate.

**Presence** — the user-facing projection boundary.

**Organ** — a component with one narrow cognitive responsibility.

**Contribution** — a typed cognitive message.

**Observation** — direct input and recommended root contribution.

**Correlation** — membership in one episode.

**Causation** — direct prior cause.

**Evidence** — additional supporting prior contributions.

**Journal** — append-only biography.

**Workspace** — bounded active context.

**Continuity** — verified persistence of identity and commitments.

**Faculty** — optional capability such as language.
