# Roadmap

## M0 — Green Build

CMake, C++, QML, QtTest, REUSE, package validation, and Nix checks pass.

## M1 — One Presence, One Journal

One Presentation backend per user session; Workspace reflects new contributions.

## M2 — Journal v2

Schema/hash versions, canonical encoding, migrations, reference validation, and terminal-outcome constraints.

## M3 — eventd

Exclusive Journal owner with IPC and accepted-contribution signals.

## M4 — Process-Isolated Organs

identityd, intentiond, predictord, selfd, workspaced, and presenced.

## M5 — Continuity

Reboot-surviving intention and verified identity migration.

## M6 — Degraded Modes

Health, capability deficits, recovery, and reconciliation.

## M7 — Distributed Node Prototype

Selective replication and partition handling.

## M8 — Optional Language Faculty

Language is a faculty, not identity or executor.

## M9 — Authorized Action Boundary

Typed proposal, criticism, authorization, Nix build/test, confirmation, execution, outcome, and rollback.
