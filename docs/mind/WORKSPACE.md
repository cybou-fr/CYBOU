# Workspace and Attention

Workspace owns bounded active context, not biography.

## Admission

```text
organ proposal
→ eventd validation and append
→ ContributionAppended
→ workspaced admission
```

## Coalition

Contributions with one correlation episode may form a coalition.

## Salience

May include kind weight, confidence, recency, independent organs, risk, goal relevance, and interruption cost. The function must be deterministic and tested.

## Recovery

Workspace rebuilds a bounded recent state after restart and updates on every accepted contribution.
