# Installation

Cybou images are development artifacts unless a release states otherwise.

Supported development paths:

- NixOS VM;
- live ISO;
- Hyper-V image;
- Calamares installation profile.

Verify checksums, target disk, UEFI compatibility, available space, and graphics mode before installation. Do not use a development image as the only copy of important data.
