07 · Questions & architecture

Frequently asked
questions.

Cybou is a sovereign, agent-native operating environment and cognitive desktop platform built in 100% Rust for Debian 13 Linux. A persistent, deterministic local control plane called Mind continuously observes, governs, and maintains the host machine, while autonomous agent capsules, models, and tools remain strictly confined and replaceable around it.

A model is not Mind. An agent is not Mind. Tool access is not permission. Conventional AI assistants collapse memory, identity, execution, and security into a single probabilistic LLM prompt. Cybou establishes an explicit zero-trust architecture: memory, identity, health, lifecycle, and recovery are separate D-Bus micro-daemons. AI agents run in kernel-enforced sandboxes (cgroups v2, Landlock LSM) and can only propose actions that pass strict policy validation.

No. Cybou is local-sufficient by design: core cognition, identity, biography, meaning parsing, and the Living Canvas desktop require zero cloud connectivity, no GPU accelerator, and no API keys. It collects and sends zero remote telemetry. External models may be leased through a governed model broker, but only behind explicit sensitivity, egress, and budget boundaries.

Living Canvas is a high-performance spatial desktop interface built entirely with Leptos and WebAssembly (Rust). It communicates over a secure, authenticated Axum web gateway with typed JSON and real-time cryptographic event streams. It features 20+ specialized cards including a sandboxed shell, unprivileged host file manager, dynamic cognitive graph, system monitor, and personal notes.

Cybou enforces a strict two-phase Action1 / Executor1 governance pipeline: agents or users propose typed actions; Mind evaluates governance policy against empirical evidence and issues an opaque single-use permit; cybou-executord carries out the physical effect; and telemetry independently re-observes the true outcome. If telemetry does not confirm success, the action is marked failed and recorded to the hash-chained Journal.
